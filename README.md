## 1. التشغيل

| الطريقة | الخطوات |
|---|---|
| **الطريقة الموصى بها** | نقر مزدوج على `تشغيل المنصة.bat` — يشغّل خادمًا محليًا على `http://127.0.0.1:8787` ويفتح المتصفح (يحتاج Node.js أو Python، وكلاهما متوفر على معظم الأجهزة). |
| **بدون خادم** | فتح `index.html` مباشرة في Chrome أو Edge. تعمل المنصة كاملة، ويُحفظ البيانات في تخزين المتصفح. |
| **على شبكة داخلية** | نسخ المجلد إلى خادم ويب (IIS / nginx) ونشره على المسار `/quality` — لا يحتاج أي قاعدة بيانات خارجية. |

> **ملاحظة:** الخط العربي (Cairo) يُحمّل من الإنترنت عند توفره، ويُستبدل تلقائيًا بخط النظام (Tahoma/Segoe UI) دون أي تأثير على الوظائف.

### حسابات الدخول التجريبية

| الحساب | كلمة المرور | الدور | ما يستطيع فعله |
|---|---|---|---|
| `admin` | `admin123` | مدير النظام | كل الوحدات + الإعدادات والمستخدمون |
| `quality` | `quality123` | مسؤول الجودة | كل وحدات الجودة + الإعدادات والتقارير |
| `committee` | `committee123` | عضو لجنة الجودة | اطلاع كامل + إدارة اجتماعات اللجنة |
| `branch` | `branch123` | مدير فرع (المنصورة) | بيانات فرعه فقط + تسجيل الشكاوى ومتابعتها |
| `viewer` | `viewer123` | اطلاع فقط | قراءة جميع التقارير والسجلات |

تظهر هذه الحسابات أسفل شاشة الدخول، ويمكن النقر عليها لتعبئة البيانات تلقائيًا.

## 3. نموذج العمل اليومي (دورة الجودة)

```
قياس  →  تحليل  →  تصحيح  →  تحقق  →  تقرير  →  تحسين
```

1. **بطاقة التقييم / التفتيش الميداني** تُدخل الدرجات، ويُحسب التصنيف والإجراء مباشرة.
2. **الشكاوى** تُسجّل برقم مرجعي، وتُحسب مهلة المعالجة تلقائيًا من نوعها، ويظهر المتأخر في التنبيهات.
3. **الملاحظات** تُوثّق بالسبب الجذري والإجراء والمسؤول والمهلة، وتُغلق بعد التحقق من الفعالية.
4. **المؤشرات** تُحسب آليًا من السجلات، وتُستكمل المؤشرات التشغيلية يدويًا شهريًا.
5. **التقارير** تُصدر وتُطبع وتُعتمد، ويُرفع الشهري للإدارة العليا، والربع سنوي لجنة الجودة.

**تجربة سريعة في 5 دقائق:** سجّل شكوى جديدة → أغلقها من زر «إغلاق» مع الإجراء والسبب الجذري → عُد إلى لوحة المعلومات ولاحظ تغيّر «نسبة حل الشكاوى» → افتح «التقارير» واختر «تقرير شهري» ثم «طباعة / PDF».

## 4. التقارير والطباعة

- أربعة قوالب: **يومي، أسبوعي، شهري، ربع سنوي**، مع اختيار التاريخ والفرع.
- التقرير يتضمن: ترويسة البنك والإدارة، رقم التقرير، الفترة، الملخص التنفيذي، جداول المؤشرات، والتوصيات المولّدة آليًا، وسطر الاعتماد والتوقيعات.
- زر **«طباعة / PDF»** يُخفي القوائم والفلاتر ويطبع ورقة التقرير فقط بتنسيق A4.
- نموذج جاهز: [`docs/نموذج-التقرير-الشهري.pdf`](docs/نموذج-التقرير-الشهري.pdf) (3 صفحات).
- تصدير CSV متاح من: الشكاوى، التقييمات، التفتيش، الملاحظات، رضا العملاء، مؤشرات الأداء (يدعم العربية في Excel).

## 5. البيانات والتخزين والنسخ الاحتياطي

- تعمل المنصة دون أي خدمة خارجية؛ تُحفظ البيانات في `localStorage` داخل متصفح الجهاز (مفتاح `kak_qc_db_v2`).
- عند التشغيل من `file://` قد يمنع بعض المتصفحات التخزين؛ فتعمل المنصة في الذاكرة وتظهر رسالة تنبيه — الحل: استخدام `تشغيل المنصة.bat` (خادم محلي).
- **النسخ الاحتياطي:** الإعدادات ← النسخ الاحتياطي ← «تنزيل نسخة احتياطية» (ملف JSON كامل) و«استعادة من ملف».
- **إعادة التهيئة:** تعيد البيانات التجريبية الافتراضية (11 فرعًا وسجلات 12 شهرًا).

### بنية البيانات (مختصرة)

```
settings    بيانات البنك، سياسة الجودة، المستهدفات
branches    الفروع والإدارات            users       المستخدمون والصلاحيات
evaluations بطاقات تقييم الجودة (100)   inspections زيارات التفتيش (12 عنصرًا)
complaints  الشكاوى + المهل والإغلاق    findings    الملاحظات والإجراءات التصحيحية
surveys     استبيانات الرضا             courses     البرامج التدريبية + المشاركون
meetings    محاضر لجنة الجودة           kpiValues   قيم المؤشرات التشغيلية الشهرية
```

├─ tests/                     صفحة معاينة + اختبار آلي (Node) بكامل الوحدات

## 9. التوصيات للانتقال إلى الإنتاج

1. **الاستضافة:** خادم داخلي (Intranet) مع شهادة HTTPS، ونشر المجلد كتطبيق ويب ثابت.
2. **قاعدة البيانات:** استبدال التخزين المحلي بـ API خلفي (Node/ASP.NET) وقاعدة بيانات مركزية (SQL Server/PostgreSQL) مع سجل تدقيق (Audit Log).
3. **الهوية:** الربط بـ Active Directory / SSO بدلًا من كلمات المرور المحلية.
4. **التكامل:** ربط «عدد العملاء» و«عدد المعاملات» و«نسبة الأخطاء» بنظام الفروع (Core Banking) لتغذية المؤشرات آليًا بدل الإدخال اليدوي.
5. **التنبيهات:** بريد/رسائل آلية عند تجاوز مهل الشكاوى والملاحظات الحرجة.
6. **النسخ الاحتياطي:** جدولة نسخ يومي مع الاحتفاظ بنسخ أسبوعية وشهرية.
7. **الاعتماد الرسمي:** اعتماد سياسة الجودة وبطاقة التقييم والمستهدفات من الإدارة العليا قبل التوسع في جميع الفروع (المرحلة الرابعة في خطة التنفيذ).
